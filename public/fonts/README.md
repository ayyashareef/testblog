# Fonts

- `waheed.otf`: MV Waheed, used for Dhivehi headings. Named after
  calligrapher Abdulla Waheed; created by Hassan Shujau and Hassan Hameed,
  re-mapped by Ahmed Niyaz. Its copyright notice restricts editing, so it
  is served exactly as distributed. It carries no explicit web licence;
  confirm you may serve it publicly.

Body text uses Inter (Google Fonts) and Noto Sans Thaana (bundled via npm).
